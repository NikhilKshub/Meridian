## What it is
Meridian is a small desktop environment that runs in the browser.
This version focuses on a simple WebOS experience with a boot screen, desktop status bar, dock, draggable windows, two working apps, and a quote widget.

## Features
- **Boot screen** — Meridian wordmark, live day/date/time, random quote, and Enter button.
- **Status bar** — shows the WebOS name, current date, and live time.
- **Dock** — launches Notes and Calculator and shows app names when hovered.
- **Draggable windows** — Notes and Calculator can be moved around the desktop and closed when finished.
- **Notes** — simple note-taking area with a live character counter and Clear button.
- **Calculator** — basic arithmetic with numbers, operators, decimals, clear, and equals.
- **Quote widget** — displays a random quote on the desktop.
- **Change Wallpaper** — right-click the desktop to choose an image and use it as the wallpaper for the current session.
